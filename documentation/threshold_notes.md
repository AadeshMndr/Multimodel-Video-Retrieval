# PHASH_SIMILARITY_THRESHOLD

| Threshold | Effect                         |
| --------- | ------------------------------ |
| 0–2       | Only exact / near-exact frames |
| 3–5       | Very strict similarity         |
| 6–8       | ✅ Good default for video dedup |
| 9–12      | Moderate similarity            |
| 13–16     | Aggressive merging             |

Max Value: 64
Min Value: 0
